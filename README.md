# bingolastbreath-legal

Les pages légales de Bingo Last Breath, servies par GitHub Pages. **Dépôt public, sans aucun code de
l'application** : il n'existe que parce que Google exige des URL publiques et stables pour la politique
de confidentialité et la suppression de compte.

- https://ticule79.github.io/bingolastbreath-legal/confidentialite/
- https://ticule79.github.io/bingolastbreath-legal/suppression-compte/
- https://ticule79.github.io/bingolastbreath-legal/conditions/
- https://ticule79.github.io/bingolastbreath-legal/mentions-legales/

GitHub Pages : Settings → Pages → Deploy from a branch → `main` / `(root)`.

Ces textes décrivent l'application **telle qu'elle doit être au lancement** (bouton « Supprimer mon
compte », signalement, blocage, purge des comptes inactifs). Voir `lancement.md` dans le projet de l'app.

## Si un texte change

Politique et conditions portent un numéro de version : une modification de fond exige de l'incrémenter,
de dater la page, et d'en informer les joueurs dans l'application.
