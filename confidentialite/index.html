Politique de confidentialité

Version 1.1 — 22 novembre 2026 (ajout de la version web).

Bingo Last Breath est un jeu de pronostics entre amis. Ce document dit exactement ce que l'application enregistre, qui le voit, combien de temps, et ce que vous pouvez exiger. Il vaut pour les joueurs, et aussi pour les personnes que les joueurs choisissent.

L'application existe en deux versions qui partagent les mêmes comptes et les mêmes groupes : l'application Android et la version web (ticule79.github.io/bingolastbreath-web), utilisable depuis un navigateur et installable sur l'écran d'accueil, notamment sur iPhone. Sauf mention contraire, ce texte vaut pour les deux.

Votre identité chez nous

Aucun mot de passe, jamais. Au premier lancement, l'application crée un compte anonyme : un identifiant aléatoire, et un jeton de connexion conservé dans l'espace privé de l'application sur votre téléphone. Vous choisissez ensuite un pseudo.

Un compte resté anonyme est perdu si vous désinstallez l'application ou changez de téléphone. Pour l'éviter, vous pouvez, si vous le souhaitez, le protéger en y rattachant :

  • une adresse e-mail : un code à usage unique vous est envoyé pour la vérifier, puis à chaque connexion sur un nouveau téléphone ;
  • ou votre compte Google : Google nous transmet alors votre identifiant Google, votre adresse e-mail, votre nom et l'adresse de votre photo de profil. Seule l'adresse e-mail est utilisée ; le reste est conservé par notre hébergeur avec l'identité Google, sans être affiché ni partagé.

Votre adresse e-mail n'est jamais visible des autres joueurs, ni utilisée pour de la prospection. Elle ne sert qu'à vous connecter et, si nécessaire, à vous écrire au sujet de votre compte.

La langue de l'application (français ou anglais) n'est enregistrée que sur votre téléphone.

Dans la version web

Le jeton de connexion est conservé dans le stockage local du navigateur, propre au site de la version web. Y sont aussi gardés : votre accord aux présentes règles (avec sa date), et une copie des dernières données affichées (vos groupes, classements et choix) pour que l'application reste consultable hors connexion. Le navigateur garde aussi les fichiers de l'application pour qu'elle s'ouvre sans réseau. Ces informations restent sur votre appareil.

Effacer les données du site dans votre navigateur fait perdre un compte resté anonyme. Sur iPhone, Safari et l'application ajoutée à l'écran d'accueil ont chacun leur propre stockage : un compte créé dans l'un n'apparaît pas dans l'autre.

Ce qui est enregistré sur notre serveur

Votre compte
L'identifiant, la date de création, la date de dernière visite, le pseudo et, si vous l'avez rattachée, votre adresse e-mail ou votre identité Google.
Vos groupes
Le nom des groupes que vous créez, leurs réglages (dates de saison, nombre de choix, options, bonus), leur code d'invitation, la liste de leurs membres et le rôle de chacun.
Vos choix
Les personnes que vous choisissez dans chaque groupe, votre joker, vos options de jeu facultatives (pari secret, mois prédit) et les points qui en découlent.
Les fiches que vous créez
Si le groupe l'autorise, vous pouvez ajouter une personne qui n'est pas dans Wikidata (une « personne non célèbre ») : son nom, sa date ou son année de naissance, une courte description, et le cas échéant sa date de décès. Voir plus bas « Les personnes choisies ».
Les journaux techniques
Comme tout serveur, celui de notre hébergeur enregistre pour chaque requête l'heure, l'adresse demandée et l'adresse IP, à des fins de sécurité et de diagnostic. Ces journaux sont effacés automatiquement au bout de quelques jours.

Rien d'autre. Pas de position, pas de contacts, pas de photos, pas d'identifiant publicitaire.

Qui voit quoi

  • Les membres de vos groupes voient votre pseudo, vos choix, votre joker, vos points et les fiches créées dans le groupe. Si les administrateurs du groupe ont choisi de cacher les choix, ceux-ci ne sont révélés qu'au début de la saison ; un pari secret reste caché jusqu'au décès de la personne.
  • Les joueurs que vous avez croisés dans un groupe voient votre pseudo dans leur liste d'amis, pour pouvoir vous inviter dans une partie suivante.
  • Personne d'autre : les groupes sont privés, accessibles seulement avec leur code.

Les personnes choisies

Cette partie s'adresse aussi aux personnes qui ne jouent pas.

Les personnalités publiques

Le nom, la courte description (en français et en anglais), la date de naissance, le cas échéant la date de décès, et le grand domaine de son métier (musique, sport, politique, cinéma et télévision, littérature, sciences) d'une personnalité sont copiés depuis Wikidata, une base de connaissances publique et libre (licence CC0). Ils servent uniquement à calculer les points du jeu. Base légale : notre intérêt légitime à proposer un jeu reposant sur des informations déjà rendues publiques, l'application n'ajoutant aucune information nouvelle sur la personne. Ces données sont conservées tant qu'une personnalité figure dans au moins un groupe ou peut y être choisie.

Vous êtes une personnalité et ne souhaitez pas figurer dans le jeu ? Écrivez à l'adresse ci-dessus : votre fiche sera supprimée et ne pourra plus être choisie, sans que vous ayez à justifier votre demande.

Les personnes non célèbres

Un joueur peut créer la fiche d'une personne qui n'est pas publique. Il s'engage, par les conditions d'utilisation, à ne le faire qu'avec l'accord de la personne concernée. La fiche n'est visible que des membres du groupe concerné et disparaît avec lui. Toute personne qui découvre sa fiche peut en obtenir la suppression immédiate en écrivant à l'adresse ci-dessus, en indiquant le nom du groupe ou son code.

Combien de temps

  • Votre compte, votre pseudo et vos choix : tant que le compte existe. Un compte inactif depuis trois ans est supprimé automatiquement, avec tout ce qui lui est rattaché.
  • Un groupe : jusqu'à sa suppression par son créateur, ou la suppression du compte de celui-ci. Quitter un groupe efface vos choix dans ce groupe.
  • Les journaux techniques : quelques jours.
  • Une demande écrite (exercice de droit, signalement) : le temps de la traiter, puis un an pour pouvoir prouver qu'elle l'a été.

Sécurité

Toutes les communications sont chiffrées (HTTPS). Sur le serveur, des règles d'accès vérifiées à chaque requête empêchent un joueur de lire un groupe dont il n'est pas membre. Le jeton de connexion reste dans l'espace privé de l'application, inaccessible aux autres applications ; il n'est pas inclus dans les sauvegardes du téléphone. Dans la version web, il reste dans le stockage du navigateur réservé au site de la version web, que les autres sites ne peuvent pas lire.
