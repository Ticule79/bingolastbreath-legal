Supprimer mon compte et mes données

Application concernée : Bingo Last Breath, éditée par Noverane.

Depuis l'application

  1. sur l'accueil, touchez le menu en haut à droite ;
  2. choisissez Supprimer mon compte ;
  3. confirmez.

La suppression est immédiate et définitive.

Ce qui est effacé

  • votre identifiant, votre pseudo, et l'adresse e-mail ou l'identité Google rattachée ;
  • vos choix et votre joker dans tous vos groupes ;
  • les groupes dont vous êtes le créateur, avec les choix de tous leurs membres et les fiches de personnes non célèbres qui y ont été créées ;
  • votre présence dans la liste d'amis des autres joueurs.

Avant de supprimer un groupe que vous avez créé, prévenez ses membres : il disparaît pour eux aussi.

Ce qui reste

Les fiches de personnes non célèbres que vous avez créées dans le groupe d'un autre joueur restent dans ce groupe, sans plus aucun lien avec vous ; leur créateur ou la personne concernée peut en demander la suppression. Les fiches de personnalités publiques, copiées de Wikidata, restent disponibles pour les autres joueurs. Les journaux techniques du serveur s'effacent d'eux-mêmes en quelques jours.

Si vous avez déjà désinstallé l'application

Si votre compte était protégé par une adresse e-mail ou Google, réinstallez l'application, choisissez J'ai déjà un compte, connectez-vous, puis supprimez-le depuis le menu. Vous pouvez aussi nous écrire depuis cette adresse e-mail.

S'il était resté anonyme, la seule preuve d'en être le titulaire était un jeton conservé dans l'application. Écrivez à novera.app.contact@gmail.com en indiquant votre pseudo et le nom ou le code d'un de vos groupes : c'est suffisant pour retrouver le compte, qui sera supprimé dans le mois. Aucune pièce d'identité ne vous sera demandée.

Sans cela, un compte inactif depuis trois ans est de toute façon supprimé automatiquement.

Supprimer seulement une partie

  • Un choix : retirez-le dans le groupe, tant que la saison n'a pas commencé.
  • Un groupe : Quitter le groupe efface vos choix dans ce groupe ; son créateur peut le supprimer entièrement.
  • Une fiche de personne non célèbre : écrivez-nous avec le nom du groupe ou son code.
